New side-by-side override diff view for consent screens: `NewDiff` for embedding on a wizard step and `ReviewDiff` for inline confirmations, with `RenderDiff` for the static record.

Build a `DiffFile` per changed file: sections carry a label, host notes, before/after presence flags, and one `DiffOp` per line. Wide terminals show before and after side by side with `+`/`-` markers; narrow ones stack before above after; long lines wrap and never truncate. Tabs expand, control characters and invisible Unicode render as `\xNN` / `\uNNNN`, and widths are grapheme-aware.

Enter confirms only on a complete, visible diff after a short settle delay, and only once an `Acknowledge` line (when configured) is armed with `y`. Cancelling can ask a `LeaveConfig` question first; Backspace and the acknowledgement exist only when the host enables them. On a confirmed inline run the whole static diff stays in the scrollback; otherwise the frame clears and the host prints the outcome.

Wizards that run each screen as its own program can now share their key rules through the step runner. `Step` runs a numbered `List`, a form behind a small `Form` adapter (teakit still does not import huh), or the leave question alone, and returns `nil`, `ErrBack`, or `ErrLeave`. While text is typed, Backspace edits it and Esc goes back; on a choice screen Backspace goes back and Esc leaves, asking first when the tool sets `Unsaved`; Ctrl+C leaves at once. A list's typed `Field` shows its unit as a fixed suffix and drops a unit typed after the number. `Wait` shows a cancellable wait: Esc cancels it and Ctrl+C leaves. Up/Down and k/j wrap around at both ends of a list, and `Move` gives a full-screen model the same movement. `Wrap` folds text as the lists do, and `LeaveConfig.Hint` replaces the leave question's key line.
