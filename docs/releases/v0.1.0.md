The first release shares the leave question between Bubble Tea applications. Enter initially keeps the user on the screen; Esc confirms leaving. Ctrl+C reports an interrupt so the application can exit the whole flow.

- Use `teakit.NewLeave` inside an existing model, or `teakit.AskLeave` to run the question as its own inline step.
- Supply the wording and any extra answer keys. The calling screen decides whether leaving needs confirmation.

Requires Go 1.25.0 and Bubble Tea v2.0.2 or later in the v2 series. From the consuming module, run `go get github.com/undervoke/teakit@v0.1.0`. See the [integration guide for this version](https://github.com/undervoke/teakit/blob/v0.1.0/docs/consumers.md).
