The diff view can offer a second answer beside Enter, for a page where the user picks between two outcomes, such as restoring an earlier value or keeping the current one. Set `DiffConfig.AlternateKey` to an exact key name and `AlternateLabel` to its hint verb. The key answers the new `DiffAlternate` under the same conditions as Enter: a complete, visible diff after the settle delay, with the `Acknowledge` line armed when one is configured. The hint line shows it next to Enter.

The diff's own keys win over `AlternateKey`, so choose one it does not bind; `k`, for example, scrolls. A confirmed `ReviewDiff` still leaves the static diff in the scrollback, while `DiffAlternate` clears the frame like back and cancel, and the host prints the outcome.

Callers that do not set `AlternateKey` see no change. Update with `go get github.com/undervoke/teakit@v0.6.0`. See the [integration guide](https://github.com/undervoke/teakit/blob/v0.6.0/docs/consumers.md#adopt-the-diff-view).
