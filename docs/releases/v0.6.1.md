A runner whose program ends before the user answers, as when the process gets SIGTERM, now returns the Ctrl+C answer: `ErrLeave` from `Step.Run` and `Wait`, `teakit.Interrupt` from `AskLeave`, and `teakit.DiffInterrupt` from `ReviewDiff`. Before, `Step.Run` returned nil as if the highlighted option had been picked, `Wait` returned a zero value with a nil error, and the questions returned `Pending`.

In the diff view, Page Down now pages, and the hint names it `pgdown`. A `CancelKeys` or `AlternateKey` entry of `pgdown` is now taken by scrolling, so choose another key for it. End, `G`, and `]` after the last section stop at the last page instead of scrolling every row away. Enter and the alternate key do not answer while no file row is visible, such as when a long title fills the view.

When cancelling asks the leave question, the question is now always drawn before it can be answered, including while the diff is loading, incomplete, or too small, where it replaces the view. If it cannot fit at all, the view asks to enlarge the terminal; Ctrl+C still exits.

No call changes are needed. Update with `go get github.com/undervoke/teakit@v0.6.1`.
