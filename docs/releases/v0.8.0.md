teakit now requires Go 1.26.0 and Bubble Tea v2.1.2, up from Go 1.25.0 and Bubble Tea v2.0.2. Earlier Bubble Tea renderers erase the alternate screen from its top-left corner when a screen gets shorter, and terminals such as iTerm2 then keep the whole screen in the scrollback.

`AltScreen` no longer leaves screens in the terminal's scrollback:
- A huh form is drawn once. The flow answers the form's window-size request itself instead of passing it to Bubble Tea, whose answer redrew the whole screen.
- Between screens, and after the last one until the flow returns, the last screen stays drawn instead of being cleared. It takes no keys there; Ctrl+C still cancels the flow's context with `ErrLeave` as its cause. Show work between screens with `Wait`, so that the screen left up does not look like it is waiting for an answer.
- Nothing is drawn until the terminal reports its size, and keys other than Ctrl+C that arrive before then are dropped, so a screen cannot be answered before it is shown.

A flow that returns before showing a screen, such as on a validation error, now makes `AltScreen` return at once. Before, on Bubble Tea v2.1, it waited until the context ended.

No call changes are needed. Update with `go get github.com/undervoke/teakit@v0.8.0`, which raises your module's `go` line to 1.26.0 and Bubble Tea to v2.1.2. Raise any toolchain you pin elsewhere, such as in CI or a bootstrap script, to Go 1.26 as well. See the [integration guide](https://github.com/undervoke/teakit/blob/v0.8.0/docs/consumers.md).
