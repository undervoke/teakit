Embedded leave questions can now use the same list or footer as the rest of the application. `LeaveModel.Cursor()` returns the currently highlighted row (0 for stay, 1 for leave) before the user answers. Use it in your renderer to show what Enter will do, and keep routing keys through `Update`.

Existing callers of `View()` and `AskLeave` need no changes. The default view, key behavior, and Go and Bubble Tea minimums are unchanged.

Update with `go get github.com/undervoke/teakit@v0.2.0`. See the [integration guide](https://github.com/undervoke/teakit/blob/v0.2.0/docs/consumers.md).
