teakit now draws multi-selects and forms itself, so a wizard no longer needs huh, and every screen has one look and one set of keys. The API and several keys change. The Go and Bubble Tea minimums stay at 1.26.0 and v2.1.2.

New:
- `MultiSelect` takes any number of numbered options. Space checks one, and `Accept` can reject the answer with a reason.
- `Form` holds `InputField`s and `SelectField`s above a Submit row. The arrows move between the fields, Enter opens one, Enter or Tab locks its answer and opens the next, and Esc undoes it. A form of one field stays open.
- `Diff` shows changes as a screen to read, file after file. Up/Down scroll it, Left/Right go to another file, and the path at the top stays with its place and its added and removed lines. It has no answer but going on; choose what to change on a screen before it.
- Roles (`Header`, `Subhead`, `Focus`, `Chosen`, `Muted`, `Success`, `Warning`, `Error`) fix how each kind of text looks. teakit's screens use them, and `teakit.Muted.Render(text)` gives one to a tool's own text. `Wrap` continues a style that spans a fold.
- `NewStepModel` embeds a step in a full-screen model.
- `Select`, `MultiSelect`, `Form` and `Diff` scroll on a short terminal.
- `go run github.com/undervoke/teakit/cmd/demo-tui@v0.9.0` shows each component and the code behind it, in place of the examples.

Keys:

| Before | Now |
|---|---|
| Backspace went back on a choice screen and in the diff | Shift+Tab goes back on every screen, in a form from its first field. Reword the hints that name Backspace |
| Esc went back in a text form | Esc asks the leave question, in every form. In a form of one field it still goes back while there is a previous screen |
| Enter or Tab moved through a hosted form's fields | Enter opens and locks a field, and the Submit row submits |
| In the diff, Enter confirmed, Backspace went back, `y`/`n` armed the acknowledgement, and `]`/`[` jumped between sections | In a `Diff`, Enter goes on, Shift+Tab goes back, and Left/Right jump between files. A held Enter still does not go on |

Migrate:

| Before | Now |
|---|---|
| `List`, `Step.List` | `Select`, `Step.Select` |
| `NewField(FieldConfig{...})`, `List.Field`, `List.FieldHint`, `field.Value()` | `&Input{...}` with the same four fields, `Select.Input`, `Select.InputHint`, `input.Value` |
| The `Form` interface around a huh form, with `Step.Text` and `Step.Hint` | `Step.Form` as a `&Form{Title, Body, Fields, Hint, OpenHint}`. Each field's `Value` or `Choice` is its answer; `Choice: -1` is none yet, which the form does not submit |
| A huh multi-select | `Step.MultiSelect`, with one `Checked` entry per option |
| `Wait(ctx, view, work)` | `Wait(ctx, WaitConfig{Title, Body, Hint}, work)`, which draws a spinner beside the title |
| `ReviewDiff(ctx, DiffConfig{Title, Body}, files)` | `(&Step{Diff: &Diff{Title, Body, Files, Hint}}).Run(ctx)`, where `Body` is a function of the width. `nil` is the old `DiffConfirm`, `ErrBack` is `DiffBack`, and `ErrLeave` is `DiffCancel` or `DiffInterrupt` |
| `DiffConfig.Leave` | `Step.Unsaved` and `Step.Leave` |
| `AlternateKey`, or one diff after another to decide each change | A `MultiSelect` or `Select` before one `Diff` of everything chosen |
| `Acknowledge` | A `Select` that asks, before or after the diff |
| `NewDiff` in a full-screen model | `NewStepModel(&Step{Diff: d})` |
| `WithIncomplete`, or a diff that is still loading | `Wait` while computing the diff, and the tool's own error |
| The diff a confirmed `ReviewDiff` left in the scrollback | Print `RenderDiff(files, width)`, which now draws one column |

Update with `go get github.com/undervoke/teakit@v0.9.0`. See the [integration guide](https://github.com/undervoke/teakit/blob/v0.9.0/docs/consumers.md).
