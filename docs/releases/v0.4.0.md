`AltScreen` runs a wizard flow on the terminal's alternate screen, so the shell's earlier text stays hidden while its programs draw inline and comes back when the flow ends. Give each program inside the same writer with `tea.WithOutput`, and print `RenderDiff` afterwards to keep a confirmed diff. See the [integration guide](https://github.com/undervoke/teakit/blob/v0.4.0/docs/consumers.md#adopt-the-step-runner).

Update with `go get github.com/undervoke/teakit@v0.4.0`.
